# Замена оформления часов

Открыть `Assets/_Project/Resources/UI/Gameplay/Clock/GameClock.prefab`.

- `Dial / Image / Source Image` — картинка циферблата, включая готовые цветные зоны.
- `Dial / Hand / Image / Source Image` — картинка стрелки.
- У обеих Image белый Color, включён Preserve Aspect и отключён Raycast Target.
- Картинки должны импортироваться как Sprite (2D and UI).
- Размер стрелки задаётся её RectTransform. Pivot (0.5, 0) — основание стрелки
  в центре циферблата; изображение стрелки должно смотреть вверх. Прозрачные
  отступы у основания изображения нужно учитывать при настройке её положения.
- На GameClockView Midnight Angle задаёт направление в 00:00; Clockwise
  выбирает направление вращения. По умолчанию полночь сверху, вращение по часовой.

Временные DefaultDial и DefaultHand находятся рядом с префабом в папке Art.
GameClockView не перезаписывает назначенные в Image спрайты при запуске.
Код меняет только поворот стрелки и дату. При необходимости спрайты можно
заменить из кода через SetDialSprite и SetHandSprite.

Рисунок зон не изменяет расписание автоматически. Время начала периодов
настраивается отдельно в DayScheduleConfig под изображение.
